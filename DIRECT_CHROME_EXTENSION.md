# Load The Chrome Extension

Follow these steps after starting the helper with `START_USACO_HELPER`.

## Chrome

1. Open `chrome://extensions`.
2. Turn on Developer Mode.
3. Click `Load unpacked`.
4. Select the `chrome-extension` folder from this project.
5. Refresh your USACO Guide IDE page.

## If Something Looks Wrong

- If Chrome says the manifest is missing, you selected the wrong folder. Select `chrome-extension`.
- If the panel does not appear, refresh the USACO Guide IDE page.
- If the buttons do not respond, close the starter window, start it again, then refresh the USACO Guide IDE page.

## Panel Controls

- Drag the top bar to move the panel.
- Drag any edge or corner to resize it.
- Click `Collapse` to shrink it.
- Click `Expand` to restore it.
