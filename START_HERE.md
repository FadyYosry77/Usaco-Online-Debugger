# Start Here

Use this file if you just want to run the tool.

## 1. Start The Helper

From this project folder:

- Windows: double-click `START_USACO_HELPER.bat`
- Linux/macOS: run `./START_USACO_HELPER.sh`

Keep the window open while using the tool.

## 2. Load The Chrome Extension

1. Open Chrome.
2. Go to `chrome://extensions`.
3. Turn on Developer Mode.
4. Click `Load unpacked`.
5. Select the `chrome-extension` folder.

If Chrome shows a manifest error, select the `chrome-extension` folder itself.

## 3. Open USACO Guide IDE

Open or refresh your USACO Guide IDE page.

The debugger panel should appear on the page. If it does not appear, click the extension icon or refresh the page once.

## What You Can Do

- Build and run C++ code
- Debug with breakpoints
- Step through code
- View variables and stack frames
- Test custom input
- Save sample tests
- Compare output with expected output
- Move, resize, collapse, and expand the panel
